PPTX Recovery — Web
===================

This bundle is the static web app. Drop the `web/` folder onto any static
host and you're done.

Hosted version (always up to date):
  https://socrtwo.github.io/pptxrecovery-SF/

Local preview:
  cd web && python3 -m http.server 8080
  # then open http://localhost:8080

Privacy
-------
Your .pptx file never leaves the browser; all processing happens locally.
