How it works

PPTX files are ZIP archives containing XML. When a file is corrupt, this tool tries three strategies in order:

  1. Standard ZIP read — opens the archive and validates each entry.
  2. Low-level scan — when the central directory is broken, scans the byte stream for ZIP local-file headers and reconstructs entries one by one.
  3. XML repair & text rescue — fixes truncated or malformed XML; pulls runs of slide text as a plain-text fallback.
